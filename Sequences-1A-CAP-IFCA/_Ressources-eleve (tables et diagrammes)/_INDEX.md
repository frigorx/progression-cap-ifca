## Règle de choix (par le professeur, selon le banc réellement utilisé)

- **Banc froid positif / domestique** → R134a.
- **Banc froid négatif / commercial** → R404A (ou R449A si substitut installé).
- **Banc clim / split** → R410A.
- **Fluide du banc non fixé dans le TP / rallye multi-postes** → `Reglette P-T multi-fluides` (couvre les trois).
